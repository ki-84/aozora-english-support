最初の読み方

  1. 本棚で作品を選び、スワイプや左右端のタップで読み進めます。
  2. 意味を確かめたい英文を一文タップすると、その文の日本語訳が開きます。
  3. 音読は下部の「音読する」から。前の文・次の文への移動や、0.5〜2倍速に対応します。
  4. 右上の「Aa」で文字や背景、ヘッドホンのボタンで音声と速度を変えられます。

よくある質問

どのように、やさしい英語にしていますか？

原作を一文ずつ直訳するのではなく、長い一文で伝えている内容をいくつもの短い英文に分け、出来事や考えの順序を追いやすくしています。難しい単語も、身近な言葉を使った短い説明に置き換えます。場面・会話・結末を残し、物語全体を中学英語を目安に語り直しています。

日本語訳はどうやって見ますか？

本文の英文を一文タップすると、その英文と対応する日本語訳が開きます。左右端のタップはページ送りです。下部の「対訳」を選ぶと、本文にも英語と日本語訳を並べられます。

日本語訳と青空文庫の原文は違いますか？

一文の日本語訳は、短く書き直した英文に合わせて独自に制作したものです。原文を読むには、対訳パネルの「青空文庫の原文」を開いてください。その文を含む段落の原文を、末尾までスクロールして確認できます。

音が出ない、または音読が止まりました。

iPhoneの音量と音声の出力先、Bluetooth接続を確認してください。「音声と速度」でApple音声を選び、再生ボタンを押してお試しください。着信やイヤホンの取り外し、対訳を開いたときは一時停止する仕様です。対訳を閉じると、その直前に再生していた場合のみ再開します。

高品質音声が選べません。

高品質音声は、約380MBのデータをすべて取得すると選択できます。「音声と速度」からダウンロードしてください。通信状態と空き容量を確認し、Wi-Fiでの取得をおすすめします。未取得の間もApple音声は使えます。

音声のダウンロードに失敗・中断した場合は？

通信状態と十分な空き容量を確認して、もう一度ダウンロードしてください。取得が完了したファイルは再利用されます。取得・合成に失敗した場合もApple音声で読むことができます。

インターネットにつながっていなくても使えますか？

10作品の本文と日本語訳・原文はアプリに同梱しています。端末に用意されているApple音声と、取得済みの高品質音声は端末内で音読します。高品質音声の初回取得、出典や問い合わせなどの外部リンクを開くときは通信が必要です。

文字が読みにくい・背景を変えたい。

読書画面右上の「Aa」から、文字サイズ・行間・背景を変えられます。「紙・白・夜」を選ぶと、設定画面の文字や操作部もその場で切り替わります。

どこまで読んだかは保存されますか？

読書位置と音読位置は別に端末へ保存します。再起動後も保存した位置へ戻れます。音読は自動開始せず、再生ボタンを押すと保存した文の先頭から再開します。アプリ内の前後操作は文単位、ロック画面の前後操作は段落単位です。

機種変更やアプリの削除をするとどうなりますか？

本アプリ独自のクラウド同期はありません。アプリを削除すると端末内の読書記録と音声データも削除されます。iOSのバックアップや端末移行からの復元はAppleの設定・機能に従います。音声モデルはバックアップの対象外のため、必要に応じて再取得してください。

中学で習った単語だけで読めますか？

中学英語を学び終えた方が読み進めやすいよう、短い文・基本的な語順・身近な言葉で制作しています。固有名詞や物語に必要な文化的な語も含みます。読みやすさには個人差があるため、難しい一文は日本語訳で確かめながらお楽しみください。

アカウント登録は必要ですか？

アプリの読書・音読にアカウント登録は不要です。サポートの問い合わせをGitHubで送信する場合のみ、GitHubへのログインが必要です。

不具合のご報告に添えてほしいこと

わかる範囲で、次の内容を添えていただくと確認がスムーズです。

  • どの画面で、何をしたときに、何が起きたか
  • iPhoneの機種・iOSとアプリのバージョン
  • 本文・訳の場合は、作品名と該当する短い文
  • 音読の場合は、Apple音声／高品質音声と再生速度

スクリーンショットは、個人情報が写っていないことを確認して添付してください。
