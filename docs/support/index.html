よくある質問

日本語訳はどうやって見ますか？

英文を一文タップすると日本語訳が開きます。読書画面の「対訳」では英語と日本語を並べて読めます。

高品質音声はどうやって使いますか？

読書画面の「音声と速度」から、約380MBの音声モデルを取得します。利用条件が表示されたら、内容を確認して同意してください。取得後は「高品質音声」を選ぶと、オフラインで音読できます。

音が出ないときは？

iPhoneの音量と音声の出力先を確認してください。「音声と速度」でApple音声を選ぶと、モデルをダウンロードせずに音読できます。

文字サイズや背景を変えるには？

読書画面の「Aa」で、文字サイズ、行間、背景を変更できます。
